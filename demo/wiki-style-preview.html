Transformer 架构

Transformer 是一种完全基于 注意力机制 的深度学习架构，由 Google 团队在 2017 年提出。它彻底改变了 NLP 领域，是 GPT、BERT 等现代大语言模型的基石。

> [!important] 核心贡献 > 用自注意力（Self-Attention）取代了 RNN 和 CNN，实现了完全并行的序列计算。这一突破使得训练超大规模模型成为可能。

一句话定义

Transformer 是一种基于 ==自注意力机制== 的编码器-解码器架构，通过并行计算处理序列数据，无需循环或卷积操作。

为什么重要

在 Transformer 出现之前，序列建模主要依赖 RNN 和 LSTM，它们存在三个核心问题：

  • 串行计算：必须按顺序处理每个 token，无法并行化
  • 长距离依赖弱：信息在长序列中逐渐衰减
  • 梯度问题：梯度消失/爆炸限制了对长序列的学习

Transformer 通过自注意力机制一次性解决了这三个问题。详见 原始论文 ↗。

核心原理

关键要素

  1. 编码器（Encoder）：将输入序列编码为连续表示，堆叠 N=6 层
  2. 解码器（Decoder）：自回归生成输出序列，同样堆叠 N=6 层
  3. 自注意力层：计算序列中每个位置与其他所有位置的关系
  4. 前馈网络（FFN）：对每个位置独立做非线性变换

运作机制

注意力计算的核心公式：

Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V

其中 Q（Query）、K（Key）、V（Value）分别由输入线性变换得到，d_k 是 Key 的维度。

> [!example] 多头注意力 > 多头注意力将 Q、K、V 投影到 h=8 个不同的子空间，分别计算注意力后拼接： > ``` > MultiHead(Q,K,V) = Concat(head_1, ..., head_h) W^O > head_i = Attention(QW_i^Q, KW_i^K, VW_i^V) > ``` > 这使得模型能同时关注不同位置的不同表示子空间。

类比理解

就像一个会议室里所有人同时交换名片一样——每个人（Query）都可以直接看向其他任何人（Key），并根据相关性决定从谁那里获取多少信息（Value），而不需要像传话游戏那样一个接一个地传递。

常见误区

  • 误区 1：Transformer 只能用于 NLP
    • 正确理解：Vision Transformer (ViT) 已证明其在图像、音频、视频等模态同样有效
  • 误区 2：注意力权重等于重要性
    • 正确理解：注意力权重反映的是 Query-Key 的相似度，不直接等同于特征重要性

注意力机制的核心思想是：对于给定的查询（Query）和一组键值对（Key-Value pairs），通过计算查询与每个键的相似度得到权重，再对对应的值进行加权求和。
